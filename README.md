# Фанпей плагины
Платные плагины для фанпей кардинала здесь бесплатно.

#AutoSmm 
Плагин на автонакрутку. Закачик присылает ссылку и через панель накрутки автоматически создаётся заказ на накрут.
Есть отслеживание заказов. Моддифицировано мной: в оригинальном плагине была проблема: сайты могли ограничить запросы бота и временно блокировали трафик.
